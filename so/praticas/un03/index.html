P07 · encontro de 60 minutos · Observação real, buffer de 1 MiB

Observe memória sem esgotar a conta

Base conceitual da unidade: Tema 1 (PDF, nova aba) · Tema 2 (PDF, nova aba).

O serviço precisa de um buffer para receber lotes. Aloque 1 MiB, toque uma posição por página e observe os próprios mapas e faltas menores. O programa termina e libera o buffer; não há teste de estresse.

Execute no terminal
free -h
getconf PAGESIZE

Cole o bloco inteiro. A linha FIM, sozinha, encerra a gravação. O fonte fica na pasta atual; repetir o bloco substitui somente esse arquivo do exercício.

Criar memoria.c
cat > memoria.c <<'FIM'
#define _POSIX_C_SOURCE 200809L
#include <stdio.h>
#include <stdlib.h>
#include <unistd.h>
#include <string.h>
#include <sys/resource.h>
static int mapa(void) {
    char linha[512];
    FILE *f=fopen("/proc/self/maps","r");
    if (!f) { perror("maps"); return 0; }
    int n=0;
    while (fgets(linha,sizeof linha,f)) {
        if (n++ < 4 || strstr(linha,"[heap]") || strstr(linha,"[stack]")) fputs(linha,stdout);
    }
    return fclose(f)==0;
}
static long faltas(void) {
    struct rusage r;
    if (getrusage(RUSAGE_SELF,&r)) return -1;
    return r.ru_minflt;
}
int main(void) {
    long pagina=sysconf(_SC_PAGESIZE);
    if (pagina<=0 || pagina>65536) return 1;
    size_t tamanho=1024*1024; /* 1 MiB; nao aumentar para provocar swap. */
    volatile unsigned char *dados=malloc(tamanho);
    if (!dados) { perror("malloc"); return 1; }
    printf("PID=%ld pagina=%ld bytes alocados=%zu\n",(long)getpid(),pagina,tamanho);
    printf("Endereco virtual do buffer=%p\n",(void *)dados);
    long antes=faltas();
    for (size_t i=0;i<tamanho;i+=(size_t)pagina) dados[i]=24;
    long depois=faltas();
    printf("Faltas menores antes=%ld depois=%ld\n",antes,depois);
    int ok=mapa();
    free((void *)dados);
    puts("Buffer liberado; mapas e contadores sao observacoes reais, nao enderecos fisicos.");
    return ok?0:1;
}
FIM
Execute no terminal
gcc -std=c11 -O0 -Wall -Wextra -Wpedantic memoria.c -o memoria
./memoria
Referência para comparação · confira após prever
PID, endereço, mapas e contadores variam.
Buffer de 1048576 bytes; página é consultada no sistema.
Não se exige aumento exato nem positivo de um contador.

malloc reserva memória para o programa; tocar páginas pode demandar trabalho adicional do kernel. Faltas menores não exigem, por definição, buscar dados em armazenamento; não são o mesmo que cache miss da CPU. O tamanho de página consultado é uma referência do sistema, não uma prova de que cada mapeamento usa apenas páginas desse tamanho. O mapa mostra regiões virtuais, incluindo bibliotecas e pilha. Um buffer grande pode ser mapeado fora de [heap]; memória liberada nem sempre volta imediatamente ao SO.

Mudança ou transferência: Reduza o buffer para 512 KiB, recompile e compare sem exigir uma diferença exata de faltas. Explique por que os endereços podem variar entre execuções e por que não podemos inferir um endereço físico por /proc/self/maps.

P08 · encontro de 60 minutos · Simulação determinística

Traduza um endereço no modelo

Base conceitual da unidade: Tema 3 (PDF, nova aba) · Tema 4 (PDF, nova aba).

O buffer agora é representado por quatro páginas virtuais de 16 bytes. A tabela contém frames [3, 5, ausente, 2]. A memória física fictícia possui oito frames. Os tamanhos são didáticos; não são os do servidor.

Cole o bloco inteiro. A linha FIM, sozinha, encerra a gravação. O fonte fica na pasta atual; repetir o bloco substitui somente esse arquivo do exercício.

Criar paginacao.c
cat > paginacao.c <<'FIM'
#include <stdio.h>
#include <stdlib.h>
/* Modelo didatico: paginas de 16 bytes, 4 paginas virtuais e 8 frames. */
int main(int argc,char **argv) {
    char *fim;
    long virtual=argc>1?strtol(argv[1],&fim,10):30;
    if (argc>2 || (argc>1 && (fim==argv[1] || *fim)) || virtual<0 || virtual>63) {
        fputs("Use endereco virtual de 0 a 63.\n",stderr); return 1;
    }
    const int tabela[]={3,5,-1,2}; /* -1: pagina nao presente. */
    int pagina=(int)virtual/16, offset=(int)virtual%16;
    printf("virtual=%ld pagina=%d offset=%d\n",virtual,pagina,offset);
    if (tabela[pagina]<0) puts("Pagina ausente: page fault no modelo; nao ha endereco fisico calculavel agora.");
    else printf("frame=%d fisico=%d\n",tabela[pagina],tabela[pagina]*16+offset);
    puts("Tabela fornecida, nao e a tabela real do processo Linux.");
    return 0;
}
FIM
Execute no terminal
gcc -std=c11 -O0 -Wall -Wextra -Wpedantic paginacao.c -o paginacao
./paginacao 30
Execute no terminal
./paginacao 32
./paginacao 63
Referência para comparação · confira após prever
30: pagina=1 offset=14; frame=5 fisico=94
32: pagina=2 offset=0; page fault no modelo
63: pagina=3 offset=15; frame=2 fisico=47

Página = endereço / tamanho; deslocamento = resto; físico = frame × tamanho + deslocamento, somente se a página estiver presente. Uma página ausente exige tratamento; o modelo não simula leitura de disco ou escolha de vítima. A TLB guarda traduções, não o conteúdo de toda a RAM. O miss da TLB não implica, por si só, página ausente.

Mudança ou transferência: Mude o frame da página 1 de 5 para 6, recompile e preveja a nova tradução de 30. Mantendo 16 bytes por página, explique por que o deslocamento permanece igual. Desenhe um índice de dois níveis e discuta o custo de tabelas sem exigir implementação.

P09 · encontro de 60 minutos · Simulação de FIFO, LRU e OPT

Escolha uma vítima para o próximo lote

Base conceitual da unidade: Tema 5 (PDF, nova aba) · Tema 6 (PDF, nova aba).

Três frames começam vazios. Use o mesmo fluxo [1,2,3,1,4,2,5,1,2,3,4,5] em todas as políticas. OPT conhece o futuro e serve como referência teórica; o programa não mede faltas reais do Linux.

Cole o bloco inteiro. A linha FIM, sozinha, encerra a gravação. O fonte fica na pasta atual; repetir o bloco substitui somente esse arquivo do exercício.

Criar paginas.c
cat > paginas.c <<'FIM'
#include <stdio.h>
#include <string.h>
/* Mesmo fluxo, tres frames, todos vazios: FIFO, LRU e OPT. */
int main(int argc,char **argv) {
    const char *modo=argc>1?argv[1]:"fifo";
    int fifo=!strcmp(modo,"fifo"), lru=!strcmp(modo,"lru"), opt=!strcmp(modo,"opt");
    if (argc>2 || (!fifo && !lru && !opt)) { fputs("Use fifo, lru ou opt.\n",stderr); return 1; }
    const int refs[]={1,2,3,1,4,2,5,1,2,3,4,5};
    int frames[]={-1,-1,-1}, ultimo[]={-1,-1,-1}, proximo=0, faltas=0;
    for (int t=0;t<12;t++) {
        int pos=-1;
        for (int j=0;j<3;j++) if (frames[j]==refs[t]) pos=j;
        int hit=pos>=0;
        if (!hit) {
            faltas++;
            for (int j=0;j<3;j++) if (frames[j]<0) { pos=j; break; }
            if (pos<0) {
                if (fifo) pos=proximo;
                if (lru) { pos=0; for (int j=1;j<3;j++) if (ultimo[j]<ultimo[pos]) pos=j; }
                if (opt) {
                    int longe=-1;
                    for (int j=0;j<3;j++) {
                        int k=t+1; while (k<12 && refs[k]!=frames[j]) k++;
                        if (k>longe) { longe=k; pos=j; }
                    }
                }
            }
            frames[pos]=refs[t];
            if (fifo) proximo=(pos+1)%3;
        }
        ultimo[pos]=t;
        printf("ref=%d %s frames=[%d,%d,%d]\n",refs[t],hit?"HIT":"FAULT",frames[0],frames[1],frames[2]);
    }
    printf("Faltas=%d Hits=%d\n",faltas,12-faltas);
    return 0;
}
FIM
Execute no terminal
gcc -std=c11 -O0 -Wall -Wextra -Wpedantic paginas.c -o paginas
./paginas fifo
Execute no terminal
./paginas lru
./paginas opt
Referência para comparação · confira após prever
FIFO: Faltas=10 Hits=2
LRU: Faltas=10 Hits=2
OPT: Faltas=7 Hits=5

FIFO considera entrada; LRU considera uso recente; OPT remove a página cujo próximo uso está mais distante ou não ocorrerá. Empates escolhem o primeiro frame. Mesma contagem de faltas não significa mesma sequência de vítimas. Uma falta não significa necessariamente swap: uma página pode ser nova, compartilhada ou associada a arquivo. Clock, working set e thrashing são discutidos pelos cenários abaixo, sem provocar pressão de memória real.

Prompt >: o shell espera o fim do bloco. Digite FIM sozinho numa linha ou interrompa com Ctrl+C e copie novamente.

Dados variáveis: PIDs, endereços e contadores não precisam coincidir com exemplos. Não substitua os seus por números esperados.
