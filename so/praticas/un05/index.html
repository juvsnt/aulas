P12 · encontro de 60 minutos · E/S POSIX real e inventário

Compare pedidos pequenos e pedidos em lote

Base conceitual da unidade: Tema 1 (PDF, nova aba) · Tema 2 (PDF, nova aba).

Quatro bytes representam um lote já coletado; não há sensor físico conectado. Compare quatro solicitações de um byte com uma solicitação de quatro bytes, identificando o buffer da aplicação e as camadas abaixo dela.

Cole o bloco inteiro. A linha FIM, sozinha, encerra a gravação. O fonte fica na pasta atual; repetir o bloco substitui somente esse arquivo do exercício.

Criar entrada_saida.c
cat > entrada_saida.c <<'FIM'
#define _POSIX_C_SOURCE 200809L
#include <stdio.h>
#include <unistd.h>
#include <fcntl.h>
#include <errno.h>
#include <string.h>
/* Chamadas POSIX em arquivos da propria pasta. Nao usa discos brutos. */
static int transferir(int fd,unsigned char *p,size_t n,int gravar,int *chamadas) {
    while (n) {
        (*chamadas)++;
        ssize_t k=gravar?write(fd,p,n):read(fd,p,n);
        if (k<0 && errno==EINTR) continue;
        if (k<=0) return 0;
        p+=k; n-=(size_t)k;
    }
    return 1;
}
int main(void) {
    unsigned char origem[]={12,18,24,30}, unidades[4], lote[4];
    int fd=open("leituras.bin",O_WRONLY|O_CREAT|O_TRUNC,0600), chamadas=0;
    if (fd<0) { perror("open"); return 1; }
    int ok=transferir(fd,origem,4,1,&chamadas);
    if (close(fd)) ok=0;
    if (!ok) return 1;
    int pequenas=0, grandes=0;
    fd=open("leituras.bin",O_RDONLY); if (fd<0) return 1;
    for (int i=0;i<4;i++) if (!transferir(fd,&unidades[i],1,0,&pequenas)) { close(fd); return 1; }
    if (close(fd)) return 1;
    fd=open("leituras.bin",O_RDONLY); if (fd<0) return 1;
    ok=transferir(fd,lote,4,0,&grandes);
    if (close(fd)) ok=0;
    if (!ok) return 1;
    int total=0; for (int i=0;i<4;i++) total+=lote[i];
    printf("Chamadas read: unitarias=%d lote=%d\n",pequenas,grandes);
    printf("Mesmo conteudo=%s Total=%d\n",memcmp(unidades,lote,4)?"nao":"sim",total);
    puts("Contagens incluem eventuais repeticoes; nao contam acessos fisicos ao disco.");
    return 0;
}
FIM

./entrada_saida
Execute no terminal
od -An -tu1 leituras.bin

Referência para comparação · confira após prever

Mesmo conteudo=sim Total=84

Dispositivos e classes variam conforme o ambiente.

O contador é incrementado por tentativa de read; a rotina trata interrupções e leituras parciais. Não usamos stdio para ler os bytes, mas isso não elimina a cache de páginas do kernel. Uma leitura de arquivo pode ser satisfeita em RAM. Listar sysfs identifica objetos expostos pelo kernel, não comprova DMA. Se o inventário estiver indisponível, registre o limite.

Modelo: 4 bytes; polling com 3 consultas por byte → 12 consultas. Interrupção por byte → 4 avisos. DMA por lote → 1 configuração e 1 aviso final.

Essas contagens de transferência são hipóteses didáticas, não eventos medidos pelo programa. Buffering reúne dados; caching mantém cópias para reuso; spooling organiza trabalhos pendentes para um dispositivo. Em sistemas reais podem existir lotes de interrupções e mecanismos híbridos.

Mudança ou transferência: No modelo, dobre o lote para oito bytes mantendo três consultas por byte: preveja as contagens. Proponha quando o serviço precisaria buffering, caching ou spooling. Não transforme contagem de read em medição de IRQ ou DMA.

P13 · encontro de 60 minutos · Inventário real e modelo de HDD

Reconstrua o caminho até o driver

Base conceitual da unidade: Tema 3 (PDF, nova aba) · Tema 4 (PDF, nova aba).

Escolha um dispositivo efetivamente listado em /sys/block. O exemplo usa identificação automática do primeiro bloco disponível, sem assumir sda ou nvme. A consulta é de leitura; não carrega módulos nem altera dispositivos.

Execute no terminal
for caminho in /sys/block/*; do
  if [ -e "$caminho" ]; then
    printf 'Objeto escolhido: %s\n' "$caminho"
    readlink -f "$caminho"
    if [ -e "$caminho/device/driver" ]; then
      readlink -f "$caminho/device/driver"
    else
      printf 'Driver nao exposto nesse caminho.\n'
    fi
    break
  fi
done
ls -l /dev/null

O primeiro objeto pode ser virtual, como loop ou um dispositivo composto. Se o caminho device/driver não existir, isso não demonstra ausência de driver. Não invente o vínculo; use o caminho completo e documentação fornecida. /dev/null é um dispositivo de caractere sem periférico físico correspondente. Nem todo dispositivo é representado por um arquivo /dev, por exemplo interfaces de rede.

Extensão: módulos e inventário, se disponíveis
Opcional · consulta de módulos e blocos
command -v lsblk lsmod modinfo
lsblk -o NAME,TYPE,SIZE,ROTA
lsmod | head -n 8

O professor pode indicar um módulo listado para consultar com modinfo NOME. Um driver pode estar integrado ao kernel e não aparecer em lsmod. Se dmesg, /proc/interrupts, lsusb ou lspci estiverem bloqueados ou ausentes, não são requisitos; use inventário permitido ou documentação, explicitando a origem.

Cole o bloco inteiro. A linha FIM, sozinha, encerra a gravação. O fonte fica na pasta atual; repetir o bloco substitui somente esse arquivo do exercício.

Criar disco.c
cat > disco.c <<'FIM'
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
/* Cilindros hipoteticos; custo = distancia, sem chegadas durante o servico. */
int main(int argc,char **argv) {
    const char *modo=argc>1?argv[1]:"fcfs";
    int sstf=!strcmp(modo,"sstf");
    if (argc>2 || (!sstf && strcmp(modo,"fcfs"))) return 1;
    int pedidos[]={10,80,20,70}, feito[4]={0}, cabeca=50, total=0;
    for (int i=0;i<4;i++) {
        int p=i;
        if (sstf) {
            p=-1;
            for (int j=0;j<4;j++)
                if (!feito[j] && (p<0 || abs(pedidos[j]-cabeca)<abs(pedidos[p]-cabeca))) p=j;
        }
        int distancia=abs(pedidos[p]-cabeca);
        printf("%d -> %d distancia=%d\n",cabeca,pedidos[p],distancia);
        total+=distancia; cabeca=pedidos[p]; feito[p]=1;
    }
    printf("Deslocamento total=%d cilindros hipoteticos\n",total);
    puts("Nao mede latencia de HDD, SSD ou o escalonador real do Linux.");
    return 0;
}
FIM
Execute no terminal
gcc -std=c11 -O0 -Wall -Wextra -Wpedantic disco.c -o disco
./disco fcfs
Execute no terminal
./disco sstf
Referência para comparação · confira após prever
FCFS: deslocamento total=220 cilindros hipotéticos
SSTF: deslocamento total=100 cilindros hipotéticos

O modelo começa no cilindro 50 e atende [10,80,20,70], sem novos pedidos; empates escolhem o primeiro ainda pendente. Deslocamento é um custo didático de HDD. SSD não tem cabeça mecânica; o resultado não prova que SSTF é melhor no servidor. RAID pode atender disponibilidade ou desempenho conforme o nível; não substitui backup e não foi configurado aqui.

Mudança ou transferência: Mude a posição inicial para 0, recompile e compare as rotas. Para o serviço com pequenos relatórios, explique por que não basta escolher armazenamento pelo menor deslocamento desse modelo. Compare HDD, SSD e uma opção de redundância sem configurar discos.

Se algo der errado

Ferramenta ausente: registre e avise o professor; não instale pacotes nem use sudo.

Prompt >: o shell espera o fim do bloco. Digite FIM sozinho numa linha ou interrompa com Ctrl+C e copie novamente.

Erro de compilação: confira se copiou o bloco inteiro, incluindo chaves e cabeçalhos. A compilação bem-sucedida normalmente não imprime nada; só execute após corrigir erros.

Permissão, quota ou criação de processo/thread bloqueada: registre a mensagem e use a alternativa documental ou o modelo no papel indicado pelo professor, sem contornar as políticas.

Dados variáveis: PIDs, endereços e contadores não precisam coincidir com exemplos. Não substitua os seus por números esperados.

Sem JavaScript: comandos, fontes e navegação continuam disponíveis. Responda em texto por outro meio; botões, progresso e download dependem de JavaScript.
