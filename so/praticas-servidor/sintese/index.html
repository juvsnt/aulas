O caminho completo de uma requisição web

Relembre o percurso que uma requisição percorre dentro do sistema operacional:

  1. Rede e E/S (Unidade 5): O pacote de rede chega pela interface física, gerando uma interrupção de hardware que o kernel atende.
  2. Chamada de Sistema (Unidade 1): A requisição cruza a fronteira do modo kernel para o modo usuário através de chamadas como read e write.
  3. Processos e Escalonamento (Unidade 2): A CPU aloca uma fatia de tempo (Round Robin) para o processo ou thread trabalhadora do servidor.
  4. Concorrência e Exclusão Mútua (Unidade 2): O contador de acessos do site é incrementado com segurança através de um Mutex.
  5. Memória Virtual e Cache (Unidade 3): O servidor consulta o buffer de páginas na memória RAM. Se a imagem não estiver presente, ocorre uma Falta de Página (Page Fault) e o kernel busca os blocos no disco.
  6. Sistema de Arquivos e Permissões (Unidade 4): O Inode do arquivo index.html é consultado para confirmar as permissões de leitura pública (644).
  7. Buffers de E/S e Logs (Unidade 5): A resposta HTTP 200 OK é transmitida de volta ao cliente e a linha de acesso é acumulada no buffer do arquivo access.log.
