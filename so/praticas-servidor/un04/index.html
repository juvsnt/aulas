O cenário do servidor

Segurança de arquivos, inodos e armazenamento físico

Um servidor web armazena arquivos públicos (como index.html e imagens, que qualquer visitante da internet pode ler) e arquivos confidenciais (como banco_senhas.dat e chaves de criptografia, que só o administrador pode acessar). No Linux, essa segurança é garantida pelas permissões de acesso (leitura, escrita e execução) armazenadas no Inode do arquivo. Além disso, o sistema de arquivos divide o disco físico em blocos de 4 KB, agrupando os dados e controlando a fragmentação interna.

P10 · 60 minutos · Inodes, links e permissões

Protegendo arquivos públicos e confidenciais do servidor

Crie um arquivo público (index.html) e um arquivo confidencial do servidor (config_segura.dat). Ajuste suas permissões com chmod e crie um link simbólico (atalho):

Execute no terminal
echo "<h1>Pagina Publica</h1>" > index.html
echo "SENHA_BANCO=secreta123" > config_segura.dat

chmod 644 index.html          # Publico: leitura para todos
chmod 600 config_segura.dat   # Confidencial: somente o dono le/escreve
ln -s index.html atalho_site.html

ls -l index.html config_segura.dat atalho_site.html
stat -c "Arquivo: %n | Inode: %i | Permissoes: %A (%a) | Links: %h" index.html config_segura.dat
Trecho esperado no terminal

P11 · 60 minutos · Mapeamento em blocos e fragmentação

Como o HTML é dividido em blocos de disco (ext4)

Crie o programa disco_blocos.c. Ele calcula a alocação de blocos de 4 KB no sistema de arquivos para um arquivo de 10.000 bytes e mede a fragmentação interna no último bloco:

Criar disco_blocos.c
cat > disco_blocos.c <<'FIM'
#include <stdio.h>
#include <stdlib.h>

#define TAMANHO_BLOCO 4096 // 4 KB por bloco no sistema de arquivos ext4

int main(int argc, char **argv) {
    long tamanho_arquivo = (argc > 1) ? atol(argv[1]) : 10000;

    printf("=== ARMAZENAMENTO NO SISTEMA DE ARQUIVOS (EXT4) ===\n");
    printf("Tamanho do arquivo index.html: %ld bytes\n", tamanho_arquivo);
    printf("Tamanho do bloco de disco:     %d bytes (4 KB)\n\n", TAMANHO_BLOCO);

    long blocos_necessarios = (tamanho_arquivo + TAMANHO_BLOCO - 1) / TAMANHO_BLOCO;
    long espaco_alocado_disco = blocos_necessarios * TAMANHO_BLOCO;
    long fragmentacao_interna = espaco_alocado_disco - tamanho_arquivo;

    printf("1. Blocos de disco alocados:   %ld bloco(s)\n", blocos_necessarios);
    printf("2. Espaco real ocupado no SSD: %ld bytes\n", espaco_alocado_disco);
    printf("3. Fragmentacao Interna:       %ld bytes (desperdicados no ultimo bloco)\n\n",
           fragmentacao_interna);

    long byte_busca = 5000;
    long bloco_logico = byte_busca / TAMANHO_BLOCO;
    long deslocamento_bloco = byte_busca % TAMANHO_BLOCO;

    printf("Localizando o byte %ld dentro do arquivo:\n", byte_busca);
    printf("-> Bloco Logico do Inode: %ld\n", bloco_logico);
    printf("-> Deslocamento no bloco: %ld bytes\n", deslocamento_bloco);

    return 0;
}
FIM
gcc -std=c11 -Wall -Wextra -O0 disco_blocos.c -o disco_blocos
./disco_blocos 10000
