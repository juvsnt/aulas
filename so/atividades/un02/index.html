0/8 etapas

O caso: três chamados no laboratório

Na véspera de uma entrega, a equipe de suporte do laboratório recebe três reclamações. Sua equipe vai investigá-las com programas próprios, observar o que o sistema operacional faz e, ao final, escrever um parecer técnico.

  1. Chamado 1 — "O terminal ficou lento."
    Quem está usando a CPU? Em que estado está cada processo? Como o escalonador divide o processador? (Investigações I1, I2 e I3)
  2. Chamado 2 — "O contador de acessos perde registros."
    Por que uma simples soma dá resultado errado quando várias threads trabalham juntas? (I4 e I5)
  3. Chamado 3 — "O programa congelou e não termina."
    O que prende duas threads para sempre — e como impedir? (I6)

Em cada investigação, siga o ciclo prever → executar → observar → interpretar → relacionar com a teoria. Escreva a previsão antes de executar. PIDs, tempos, endereços e contagens mudam a cada execução: registre os seus valores, nunca copie os da referência.

Extensões. Os trechos marcados como extensão (disputa com nice na I3 e semáforo na I5) são feitos em aula se houver tempo; caso contrário, complete-os depois, antes de entregar o relatório.

Teoria de apoio: t01 Processos · t02 Execução · t03 fork/exec · t04 Threads · t05 Escalonamento · t06 Algoritmos · t07 Concorrência · t08 Sincronização e deadlock (PDFs, nova aba).

/* carga.c - processo CPU-bound com duracao limitada.
 * Uso: ./carga [segundos]   (padrao 3, maximo 30)
 * Calcula sem parar ate o relogio de parede atingir o limite e informa
 * quanto tempo de CPU realmente recebeu e quantas trocas de contexto sofreu.
 * Chamado 1 (I1, I3). */
#define _XOPEN_SOURCE 700
#include <stdio.h>
#include <stdlib.h>
#include <time.h>
#include <unistd.h>
#include <sys/resource.h>

#define PADRAO 3
#define MAXIMO 30

static double agora(clockid_t relogio) {
    struct timespec t;
    clock_gettime(relogio, &t);
    return (double)t.tv_sec + (double)t.tv_nsec / 1e9;
}

int main(int argc, char *argv[]) {
    int segundos = PADRAO;
    if (argc > 1) segundos = atoi(argv[1]);
    if (segundos < 1 || segundos > MAXIMO) {
        fprintf(stderr, "Use um valor entre 1 e %d segundos.\n", MAXIMO);
        return 1;
    }
    int ni = getpriority(PRIO_PROCESS, 0);
    printf("carga PID=%d PPID=%d nice=%d: calculando por %d s\n",
           (int)getpid(), (int)getppid(), ni, segundos);
    fflush(stdout);

    double inicio = agora(CLOCK_MONOTONIC);
    volatile unsigned long long soma = 0;
    unsigned long long voltas = 0;
    while (agora(CLOCK_MONOTONIC) - inicio < segundos) {
        for (unsigned long long i = 0; i < 100000; i++) soma += i * i;
        voltas++;
    }

    double parede = agora(CLOCK_MONOTONIC) - inicio;
    double cpu = agora(CLOCK_PROCESS_CPUTIME_ID);
    struct rusage uso;
    getrusage(RUSAGE_SELF, &uso);
    printf("carga PID=%d nice=%d | parede=%.2f s | CPU=%.2f s (%.0f%%) | "
           "blocos=%llu | trocas voluntarias=%ld involuntarias=%ld\n",
           (int)getpid(), ni, parede, cpu, 100.0 * cpu / parede, voltas,
           uso.ru_nvcsw, uso.ru_nivcsw);
    return 0;
}

/* espera.c - processo I/O-bound simulado, com duracao limitada.
 * Uso: ./espera [segundos]   (padrao 3, maximo 60)
 * Alterna rajadas curtas de CPU (cerca de 1 ms) com pausas de 50 ms,
 * como um programa que espera teclado, disco ou rede.
 * Compare a saida com a de ./carga. Chamado 1 (I1, I3). */
#define _XOPEN_SOURCE 700
#include <stdio.h>
#include <stdlib.h>
#include <time.h>
#include <unistd.h>
#include <sys/resource.h>

#define PADRAO 3
#define MAXIMO 60

static double agora(clockid_t relogio) {
    struct timespec t;
    clock_gettime(relogio, &t);
    return (double)t.tv_sec + (double)t.tv_nsec / 1e9;
}

int main(int argc, char *argv[]) {
    int segundos = PADRAO;
    if (argc > 1) segundos = atoi(argv[1]);
    if (segundos < 1 || segundos > MAXIMO) {
        fprintf(stderr, "Use um valor entre 1 e %d segundos.\n", MAXIMO);
        return 1;
    }
    printf("espera PID=%d PPID=%d: alternando CPU e pausa por %d s\n",
           (int)getpid(), (int)getppid(), segundos);
    fflush(stdout);

    const struct timespec pausa = {0, 50 * 1000 * 1000}; /* 50 ms */
    double inicio = agora(CLOCK_MONOTONIC);
    volatile unsigned long long soma = 0;
    unsigned long long rajadas = 0;
    while (agora(CLOCK_MONOTONIC) - inicio < segundos) {
        double fim_rajada = agora(CLOCK_MONOTONIC) + 0.001; /* 1 ms de CPU */
        while (agora(CLOCK_MONOTONIC) < fim_rajada) soma += 1;
        rajadas++;
        nanosleep(&pausa, NULL); /* o processo fica Bloqueado (estado S) */
    }

    double parede = agora(CLOCK_MONOTONIC) - inicio;
    double cpu = agora(CLOCK_PROCESS_CPUTIME_ID);
    struct rusage uso;
    getrusage(RUSAGE_SELF, &uso);
    printf("espera PID=%d | parede=%.2f s | CPU=%.2f s (%.0f%%) | "
           "rajadas=%llu | trocas voluntarias=%ld involuntarias=%ld\n",
           (int)getpid(), parede, cpu, 100.0 * cpu / parede, rajadas,
           uso.ru_nvcsw, uso.ru_nivcsw);
    return 0;
}

/* ciclo.c - nascimento, substituicao e fim de processos.
 * Uso: ./ciclo exec | ./ciclo zumbi [segundos] | ./ciclo orfao
 *   exec  : fork + exec; o filho vira "ps" sem trocar de PID.
 *   zumbi : o filho termina e o pai demora a chamar wait (padrao 5 s, max 30).
 *   orfao : o pai termina antes do filho; o filho e adotado.
 * Todos os modos terminam sozinhos. Chamado 1 (I2). */
#define _XOPEN_SOURCE 700
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <time.h>
#include <unistd.h>
#include <sys/types.h>
#include <sys/wait.h>

static void dormir_ms(long ms) {
    struct timespec t = {ms / 1000, (ms % 1000) * 1000000L};
    nanosleep(&t, NULL);
}

/* Mostra uma linha do ps para o PID indicado (ou avisa que nao existe). */
static void mostrar(pid_t pid) {
    char cmd[96];
    snprintf(cmd, sizeof cmd,
             "ps -o pid=,ppid=,stat=,comm= -p %d || echo '   (PID %d nao existe mais)'",
             (int)pid, (int)pid);
    fflush(stdout);
    if (system(cmd) == -1) perror("system");
}

static void relatar(pid_t filho, int status) {
    if (WIFEXITED(status))
        printf("pai: wait recolheu o filho %d, codigo de saida %d\n",
               (int)filho, WEXITSTATUS(status));
    else if (WIFSIGNALED(status))
        printf("pai: wait recolheu o filho %d, encerrado pelo sinal %d\n",
               (int)filho, WTERMSIG(status));
}

static int modo_exec(void) {
    printf("pai PID=%d: chamando fork()\n", (int)getpid());
    fflush(stdout);
    pid_t pid = fork();
    if (pid < 0) { perror("fork"); return 1; }
    if (pid == 0) {
        printf("filho PID=%d PPID=%d: fork() retornou 0; chamando exec(ps)\n",
               (int)getpid(), (int)getppid());
        fflush(stdout);
        char alvo[16];
        snprintf(alvo, sizeof alvo, "%d", (int)getpid());
        execlp("ps", "ps", "-o", "pid,ppid,stat,comm", "-p", alvo, (char *)NULL);
        perror("exec"); /* so chega aqui se o exec falhar */
        _exit(127);
    }
    printf("pai: fork() retornou %d (PID do filho); aguardando com wait\n", (int)pid);
    fflush(stdout);
    int status;
    if (waitpid(pid, &status, 0) < 0) { perror("wait"); return 1; }
    relatar(pid, status);
    return 0;
}

static int modo_zumbi(int segundos) {
    pid_t pid = fork();
    if (pid < 0) { perror("fork"); return 1; }
    if (pid == 0) _exit(7); /* o filho termina imediatamente com codigo 7 */

    printf("pai PID=%d criou o filho %d, que ja terminou.\n", (int)getpid(), (int)pid);
    printf("pai: vou esperar %d s ANTES de chamar wait.\n", segundos);
    dormir_ms(500);
    printf("Estado do filho agora (PID PPID STAT COMANDO):\n");
    mostrar(pid);
    printf("Em outro terminal: ps -o pid,ppid,stat,comm --ppid %d\n", (int)getpid());
    fflush(stdout);
    dormir_ms(segundos * 1000L);

    int status;
    if (waitpid(pid, &status, 0) < 0) { perror("wait"); return 1; }
    relatar(pid, status);
    printf("Estado do filho depois do wait:\n");
    mostrar(pid);
    return 0;
}

static int modo_orfao(void) {
    pid_t pid = fork();
    if (pid < 0) { perror("fork"); return 1; }
    if (pid == 0) {
        printf("filho PID=%d: meu PPID agora e %d\n", (int)getpid(), (int)getppid());
        fflush(stdout);
        dormir_ms(2000); /* o pai termina durante esta pausa */
        printf("filho PID=%d: depois que o pai terminou, meu PPID e %d\n",
               (int)getpid(), (int)getppid());
        mostrar(getppid());
        fflush(stdout);
        _exit(0);
    }
    printf("pai PID=%d: vou terminar sem esperar o filho %d\n", (int)getpid(), (int)pid);
    fflush(stdout);
    dormir_ms(500);
    printf("pai PID=%d: terminando (o prompt pode voltar antes do filho escrever)\n",
           (int)getpid());
    return 0;
}

int main(int argc, char *argv[]) {
    if (argc > 1 && strcmp(argv[1], "exec") == 0) return modo_exec();
    if (argc > 1 && strcmp(argv[1], "orfao") == 0) return modo_orfao();
    if (argc > 1 && strcmp(argv[1], "zumbi") == 0) {
        int s = argc > 2 ? atoi(argv[2]) : 5;
        if (s < 1 || s > 30) { fputs("Use entre 1 e 30 segundos.\n", stderr); return 1; }
        return modo_zumbi(s);
    }
    fputs("Uso: ./ciclo exec | ./ciclo zumbi [segundos] | ./ciclo orfao\n", stderr);
    return 1;
}

/* threads.c - um processo, varios fluxos de execucao.
 * Uso: ./threads [segundos]   (padrao 15, maximo 60)
 * Cria 3 threads que ficam ativas pelo tempo indicado. Cada uma mostra seu
 * TID e os enderecos de uma variavel global (compartilhada) e de uma local
 * (na pilha privada da thread). Chamado 2 (I4).
 * Compile com: gcc -std=c11 -Wall -Wextra threads.c -o threads -pthread */
#define _GNU_SOURCE /* gettid() */
#include <stdio.h>
#include <stdlib.h>
#include <time.h>
#include <unistd.h>
#include <pthread.h>

#define NTHREADS 3

static int global = 0;                       /* segmento de dados: compartilhado */
static int segundos = 15;
static pthread_mutex_t saida = PTHREAD_MUTEX_INITIALIZER;

static void *trabalhar(void *arg) {
    int numero = *(int *)arg;
    int local = numero * 100;                /* pilha desta thread: privada */
    pthread_mutex_lock(&saida);
    printf("thread %d | PID=%d TID=%d | &global=%p | &local=%p (local=%d)\n",
           numero, (int)getpid(), (int)gettid(), (void *)&global, (void *)&local, local);
    fflush(stdout);
    pthread_mutex_unlock(&saida);
    struct timespec t = {segundos, 0};
    nanosleep(&t, NULL);                     /* fica viva para ser observada */
    return NULL;
}

int main(int argc, char *argv[]) {
    if (argc > 1) segundos = atoi(argv[1]);
    if (segundos < 1 || segundos > 60) {
        fputs("Use entre 1 e 60 segundos.\n", stderr);
        return 1;
    }
    printf("main     | PID=%d TID=%d | &global=%p\n",
           (int)getpid(), (int)gettid(), (void *)&global);
    printf("Observe em ate %d s: ps -T -p %d   e   ls /proc/%d/task\n",
           segundos, (int)getpid(), (int)getpid());
    fflush(stdout);

    pthread_t t[NTHREADS];
    int numeros[NTHREADS];
    for (int i = 0; i < NTHREADS; i++) {
        numeros[i] = i + 1;
        if (pthread_create(&t[i], NULL, trabalhar, &numeros[i]) != 0) {
            fputs("Falha ao criar thread; avise o professor.\n", stderr);
            return 1;
        }
    }
    for (int i = 0; i < NTHREADS; i++) pthread_join(t[i], NULL);
    puts("main: todas as threads terminaram (pthread_join).");
    return 0;
}

/* contador.c - o contador de acessos que perde registros.
 * Uso: ./contador sem | ingenuo | mutex | semaforo
 *   sem      : 4 threads somam 1 no contador, sem protecao.
 *   ingenuo  : protecao com uma variavel "ocupado" (trava ingenua).
 *   mutex    : protecao com pthread_mutex.
 *   semaforo : 5 threads disputam 3 vagas controladas por um semaforo.
 * Chamado 2 (I5). Compile com -pthread.
 *
 * Nota tecnica: cada acesso ao contador e atomico isolado (atomic_load e
 * atomic_store), para o programa nao ter comportamento indefinido em C.
 * Mesmo assim LER + SOMAR + GRAVAR, feitos em passos separados, NAO formam
 * uma operacao atomica. Em cerca de 1 a cada 8 incrementos, sorteados, um
 * sched_yield() entre os passos alarga a janela em que outra thread pode
 * entrar, para a falha aparecer (e variar) mesmo com uma unica CPU. */
#define _XOPEN_SOURCE 700
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <time.h>
#include <sched.h>
#include <pthread.h>
#include <semaphore.h>
#include <stdatomic.h>

#define NTHREADS 4
#define VOLTAS 20000
#define RODADAS 3

enum modo { SEM, INGENUO, MUTEX };
static enum modo modo;
static atomic_int contador;
static atomic_int ocupado;                       /* trava ingenua */
static pthread_mutex_t trava = PTHREAD_MUTEX_INITIALIZER;

/* Sorteio simples (xorshift) para decidir quando abrir a janela. */
static int sorteia_janela(unsigned *s) {
    *s ^= *s << 13; *s ^= *s >> 17; *s ^= *s << 5;
    return (*s & 7u) == 0;                       /* verdadeiro em ~1/8 das vezes */
}

static void somar_um(unsigned *s) {              /* a regiao critica */
    int valor = atomic_load(&contador);          /* 1. LER */
    if (sorteia_janela(s)) sched_yield();        /* janela: outra thread pode entrar */
    valor = valor + 1;                           /* 2. PROCESSAR */
    atomic_store(&contador, valor);              /* 3. ESCREVER */
}

static void *trabalhar(void *arg) {
    unsigned semente = (unsigned)*(int *)arg * 2654435761u ^ (unsigned)time(NULL);
    if (semente == 0) semente = 1;
    unsigned *s = &semente;
    for (int i = 0; i < VOLTAS; i++) {
        if (modo == SEM) {
            somar_um(s);
        } else if (modo == INGENUO) {
            while (atomic_load(&ocupado)) sched_yield(); /* testa...           */
            if (sorteia_janela(s)) sched_yield();        /* ...alguem pode passar aqui */
            atomic_store(&ocupado, 1);                   /* ...e so depois marca */
            somar_um(s);
            atomic_store(&ocupado, 0);
        } else {
            pthread_mutex_lock(&trava);
            somar_um(s);
            pthread_mutex_unlock(&trava);
        }
    }
    return NULL;
}

static int rodar_contador(void) {
    const char *nomes[] = {"sem protecao", "trava ingenua", "mutex"};
    int esperado = NTHREADS * VOLTAS;
    printf("Modo: %s | %d threads x %d incrementos = %d esperado\n",
           nomes[modo], NTHREADS, VOLTAS, esperado);
    for (int r = 1; r <= RODADAS; r++) {
        atomic_store(&contador, 0);
        atomic_store(&ocupado, 0);
        pthread_t t[NTHREADS];
        int ids[NTHREADS];
        for (int i = 0; i < NTHREADS; i++) {
            ids[i] = r * 10 + i + 1;             /* semente diferente por thread e rodada */
            if (pthread_create(&t[i], NULL, trabalhar, &ids[i]) != 0) {
                fputs("Falha ao criar thread; avise o professor.\n", stderr);
                return 1;
            }
        }
        for (int i = 0; i < NTHREADS; i++) pthread_join(t[i], NULL);
        int obtido = atomic_load(&contador);
        printf("  rodada %d: contador=%d | perdidos=%d\n", r, obtido, esperado - obtido);
    }
    return 0;
}

/* ---------- modo semaforo: 3 vagas para 5 threads ---------- */
#define CLIENTES 5
#define VAGAS 3
static sem_t vagas;
static int dentro, maximo;                       /* protegidos pelo mutex "registro" */
static pthread_mutex_t registro = PTHREAD_MUTEX_INITIALIZER;
static struct timespec t0;

static double decorrido(void) {
    struct timespec t;
    clock_gettime(CLOCK_MONOTONIC, &t);
    return (double)(t.tv_sec - t0.tv_sec) + (double)(t.tv_nsec - t0.tv_nsec) / 1e9;
}

/* Atualiza a ocupacao (delta = +1, -1 ou 0) e imprime no mesmo passo,
 * para o registro sair na ordem real dos acontecimentos. */
static void registrar(int id, const char *evento, int delta) {
    pthread_mutex_lock(&registro);
    dentro += delta;
    if (dentro > maximo) maximo = dentro;
    printf("  t=%.2f s  thread %d %-7s (dentro=%d)\n", decorrido(), id, evento, dentro);
    fflush(stdout);
    pthread_mutex_unlock(&registro);
}

static void *cliente(void *arg) {
    int id = *(int *)arg;
    registrar(id, "chegou", 0);
    sem_wait(&vagas);                            /* wait(S): ocupa uma vaga ou bloqueia */
    registrar(id, "entrou", +1);
    struct timespec uso = {0, 400 * 1000 * 1000}; /* usa a vaga por 0,4 s */
    nanosleep(&uso, NULL);
    registrar(id, "saiu", -1);
    sem_post(&vagas);                            /* signal(S): libera a vaga */
    return NULL;
}

static int rodar_semaforo(void) {
    printf("Modo: semaforo | %d threads, %d vagas (S inicial = %d)\n", CLIENTES, VAGAS, VAGAS);
    if (sem_init(&vagas, 0, VAGAS) != 0) { perror("sem_init"); return 1; }
    clock_gettime(CLOCK_MONOTONIC, &t0);
    pthread_t t[CLIENTES];
    int ids[CLIENTES];
    for (int i = 0; i < CLIENTES; i++) {
        ids[i] = i + 1;
        if (pthread_create(&t[i], NULL, cliente, &ids[i]) != 0) {
            fputs("Falha ao criar thread; avise o professor.\n", stderr);
            return 1;
        }
    }
    for (int i = 0; i < CLIENTES; i++) pthread_join(t[i], NULL);
    sem_destroy(&vagas);
    printf("Maximo de threads dentro ao mesmo tempo: %d (limite %d)\n", maximo, VAGAS);
    return 0;
}

int main(int argc, char *argv[]) {
    const char *m = argc > 1 ? argv[1] : "";
    if (strcmp(m, "sem") == 0)      { modo = SEM;     return rodar_contador(); }
    if (strcmp(m, "ingenuo") == 0)  { modo = INGENUO; return rodar_contador(); }
    if (strcmp(m, "mutex") == 0)    { modo = MUTEX;   return rodar_contador(); }
    if (strcmp(m, "semaforo") == 0) return rodar_semaforo();
    fputs("Uso: ./contador sem | ingenuo | mutex | semaforo\n", stderr);
    return 1;
}

/* impasse.c - o programa que congela (deadlock controlado).
 * Uso: ./impasse opostos [segundos] | ./impasse ordenado
 *   opostos : thread 1 pega A e pede B; thread 2 pega B e pede A.
 *             Cada uma desiste apos o prazo (padrao 5 s, maximo 20), entao
 *             o impasse e DETECTADO e o programa termina sozinho.
 *   ordenado: as duas pedem A e depois B (ordenacao global): sem impasse.
 * Chamado 3 (I6). Compile com -pthread. */
#define _XOPEN_SOURCE 700
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <errno.h>
#include <time.h>
#include <unistd.h>
#include <pthread.h>

static pthread_mutex_t A = PTHREAD_MUTEX_INITIALIZER;
static pthread_mutex_t B = PTHREAD_MUTEX_INITIALIZER;
static pthread_mutex_t saida = PTHREAD_MUTEX_INITIALIZER;
static int prazo = 5;

struct papel {
    int id;
    pthread_mutex_t *primeiro, *segundo;
    const char *nome1, *nome2;
    int conseguiu;
};

static void dizer(int id, const char *msg, const char *recurso) {
    pthread_mutex_lock(&saida);
    printf("thread %d: %s %s\n", id, msg, recurso);
    fflush(stdout);
    pthread_mutex_unlock(&saida);
}

static void *executar(void *arg) {
    struct papel *p = arg;
    pthread_mutex_lock(p->primeiro);
    dizer(p->id, "segura", p->nome1);
    struct timespec pausa = {0, 200 * 1000 * 1000};  /* da tempo a outra pegar o seu */
    nanosleep(&pausa, NULL);

    dizer(p->id, "pede", p->nome2);
    struct timespec limite;
    clock_gettime(CLOCK_REALTIME, &limite);
    limite.tv_sec += prazo;
    int r = pthread_mutex_timedlock(p->segundo, &limite); /* bloqueia ate o prazo */
    if (r == 0) {
        dizer(p->id, "conseguiu tambem", p->nome2);
        p->conseguiu = 1;
        pthread_mutex_unlock(p->segundo);
    } else if (r == ETIMEDOUT) {
        dizer(p->id, "DESISTIU apos o prazo; continua sem", p->nome2);
    } else {
        dizer(p->id, "erro inesperado ao pedir", p->nome2);
    }
    pthread_mutex_unlock(p->primeiro);
    dizer(p->id, "liberou", p->nome1);
    return NULL;
}

int main(int argc, char *argv[]) {
    const char *m = argc > 1 ? argv[1] : "";
    int opostos;
    if (strcmp(m, "opostos") == 0) opostos = 1;
    else if (strcmp(m, "ordenado") == 0) opostos = 0;
    else { fputs("Uso: ./impasse opostos [segundos] | ./impasse ordenado\n", stderr); return 1; }
    if (opostos && argc > 2) prazo = atoi(argv[2]);
    if (prazo < 1 || prazo > 20) { fputs("Use um prazo entre 1 e 20 segundos.\n", stderr); return 1; }

    printf("PID=%d | modo %s | prazo de espera %d s\n", (int)getpid(), m, prazo);
    if (opostos)
        printf("Observe em outro terminal: ps -L -o pid,lwp,stat,pcpu,comm -p %d\n", (int)getpid());
    fflush(stdout);

    struct papel p1 = {1, &A, &B, "A", "B", 0};
    struct papel p2 = opostos ? (struct papel){2, &B, &A, "B", "A", 0}
                              : (struct papel){2, &A, &B, "A", "B", 0};
    pthread_t t1, t2;
    if (pthread_create(&t1, NULL, executar, &p1) != 0 ||
        pthread_create(&t2, NULL, executar, &p2) != 0) {
        fputs("Falha ao criar thread; avise o professor.\n", stderr);
        return 1;
    }
    pthread_join(t1, NULL);
    pthread_join(t2, NULL);

    if (p1.conseguiu && p2.conseguiu)
        puts("Resultado: as duas threads concluiram. Sem impasse.");
    else
        puts("Resultado: IMPASSE detectado - cada thread esperava um recurso preso pela outra.");
    return 0;
}

#!/usr/bin/env bash
# investigar.sh - atalhos de observacao da Atividade da Unidade II.
# Somente consulta processos do proprio usuario; sem sudo, instalacao ou rede.
# Uso: ./investigar.sh compilar | estado PID | arvore | threads PID | disputa [s] | limpar
set -u
PROGRAMAS="carga espera ciclo threads contador impasse"

uso() {
  cat <<'TEXTO'
Uso:
  ./investigar.sh compilar        compila os seis programas
  ./investigar.sh estado PID      "prontuario" do processo (/proc/PID/status)
  ./investigar.sh arvore          seus processos em arvore (PID, PPID, estado, nice)
  ./investigar.sh threads PID     threads do processo (ps -T e /proc/PID/task)
  ./investigar.sh disputa [s]     duas cargas no mesmo nucleo: nice 0 x nice 10
  ./investigar.sh limpar          encerra programas desta atividade que ficaram ativos
TEXTO
}

compilar() {
  local ok=0
  for p in $PROGRAMAS; do
    if gcc -std=c11 -Wall -Wextra -O0 "$p.c" -o "$p" -pthread; then
      printf 'OK %s\n' "$p"
    else
      printf 'FALHOU %s (avise o professor)\n' "$p"; ok=1
    fi
  done
  return $ok
}

exige_pid() {
  if [[ -z "${1:-}" || ! -d "/proc/$1" ]]; then
    echo "Informe o PID de um processo ativo. Ex.: ./investigar.sh estado 1234" >&2
    exit 1
  fi
}

estado() {
  exige_pid "${1:-}"
  grep -E '^(Name|State|Pid|PPid|Threads|voluntary_ctxt_switches|nonvoluntary_ctxt_switches):' \
    "/proc/$1/status"
  printf 'Nice:\t%s\n' "$(ps -o ni= -p "$1" | tr -d ' ')"
}

arvore() {
  ps -u "$USER" -o pid,ppid,stat,ni,time,comm --forest
}

threads() {
  exige_pid "${1:-}"
  ps -T -o pid,spid,stat,time,comm -p "$1"
  printf 'Diretorios em /proc/%s/task: ' "$1"
  ls "/proc/$1/task" | tr '\n' ' '; echo
}

disputa() {
  local s="${1:-5}"
  [[ -x ./carga ]] || { echo "Compile antes: ./investigar.sh compilar" >&2; exit 1; }
  local fixar=""
  if command -v taskset >/dev/null 2>&1 && taskset -c 0 true 2>/dev/null; then
    fixar="taskset -c 0"
    echo "As duas cargas foram fixadas no nucleo 0 (taskset)."
  else
    echo "AVISO: taskset indisponivel; as cargas podem usar nucleos diferentes."
  fi
  echo "Disputando a CPU por $s s: carga com nice 0 e carga com nice 10..."
  $fixar ./carga "$s" &
  $fixar nice -n 10 ./carga "$s" &
  wait
}

limpar() {
  local achou=0
  for p in $PROGRAMAS; do
    for pid in $(pgrep -u "$USER" -x "$p"); do
      kill -CONT "$pid" 2>/dev/null   # um processo parado (T) precisa continuar para receber TERM
      kill -TERM "$pid" 2>/dev/null && { echo "encerrado: $p (PID $pid)"; achou=1; }
    done
  done
  [[ $achou -eq 1 ]] || echo "Nenhum programa da atividade estava ativo."
}

case "${1:-}" in
  compilar) compilar ;;
  estado)   estado "${2:-}" ;;
  arvore)   arvore ;;
  threads)  threads "${2:-}" ;;
  disputa)  disputa "${2:-5}" ;;
  limpar)   limpar ;;
  *)        uso; exit 1 ;;
esac

O prontuário do processo

O SO mantém para cada processo um PCB com identificação, estado, contexto e recursos. No Linux, parte dessas informações aparece em /proc/PID/status. Você vai iniciar dois processos em segundo plano: carga só calcula; espera calcula um pouco e dorme muito.

Execute no terminal
./carga 15 &
pid_carga=$!
./espera 15 &
pid_espera=$!
sleep 1
./investigar.sh estado "$pid_carga"
./investigar.sh estado "$pid_espera"

Agora provoque transições no processo carga com sinais: STOP suspende e CONT retoma. É o mesmo que fazer Ctrl+Z e bg num processo em primeiro plano.

Execute no terminal
kill -STOP "$pid_carga"
./investigar.sh estado "$pid_carga" | grep State
kill -CONT "$pid_carga"
sleep 0.5
./investigar.sh estado "$pid_carga" | grep State
./investigar.sh arvore
wait
Referência para comparação · confira após prever
State:   R (running)      carga, enquanto calcula
State:   S (sleeping)     espera, quase sempre
State:   T (stopped)      carga, depois de STOP
State:   R (running)      carga, depois de CONT
PPid de carga e de espera = PID do seu bash (veja na árvore)
Ao final, carga e espera imprimem CPU usada e trocas de contexto.

O wait espera os dois processos terminarem (até 15 s). No Linux, R reúne Pronto e Executando; S corresponde a Bloqueado/Esperando; T (parado por sinal) não aparece no diagrama de cinco estados do t01; Z é o processo terminado que ainda não foi recolhido.

Nascimento, substituição e fim

No Unix, um processo nasce de outro por fork(), pode trocar de programa com exec() e termina com exit(); o pai recolhe o resultado com wait(). O programa ciclo mostra três momentos dessa vida.

Execute no terminal
./ciclo exec
./ciclo zumbi 5
./ciclo orfao
sleep 3
Referência para comparação · confira após prever
exec : o filho continua com o MESMO PID, mas o comando passa a ser ps; status 0
zumbi: o filho aparece com STAT Z até o wait; depois o PID não existe mais; código 7
orfao: o PPID do filho muda depois que o pai termina
       (no Linux tradicional, para o PID 1; em contêineres e no WSL pode ser
        outro processo "adotante", chamado subreaper)

No modo orfao, o prompt pode voltar antes das últimas linhas do filho: o shell só espera o pai. É por isso que o bloco termina com sleep 3.

Chamado 1 · I3 · cerca de 16 min · t02, t05, t06

Quem usa e quem espera a CPU

Processos alternam rajadas de CPU e esperas de E/S. Um processo CPU-bound quase não espera; um I/O-bound passa a maior parte do tempo bloqueado. As trocas de contexto voluntárias acontecem quando o processo cede a CPU (bloqueio); as involuntárias, quando o escalonador a retira (preempção).

Execute no terminal
./carga 3
./espera 3
Referência para comparação · confira após prever
carga  | parede=3.00 s | CPU perto de 3 s (perto de 100%) | voluntarias ~0  | involuntarias > 0
espera | parede=3.0x s | CPU bem pequena (poucos %)        | voluntarias ~60 | involuntarias ~0

Extensão · disputa pela CPU

Duas cargas idênticas disputam o mesmo núcleo: uma com prioridade normal (nice 0) e outra rebaixada (nice 10). Quanto maior o nice, menor a prioridade. Usuários comuns só podem aumentar o nice.

Execute no terminal
./investigar.sh disputa 5
Referência para comparação · confira após prever
nice=0  recebe a maior parte da CPU (perto de 90%)
nice=10 continua avançando, com uma fatia pequena (perto de 10%)
As duas terminam juntas, porque cada uma calcula por 5 s de relógio.
Se taskset estiver indisponível, as cargas podem ir para núcleos diferentes
e as duas chegam perto de 100%: registre isso como limite do ambiente.
Mudança orientada. Preveja a divisão com nice 5 e confira: taskset -c 0 ./carga 5 & taskset -c 0 nice -n 5 ./carga 5 & wait

Um processo, vários fluxos

Uma thread é um fluxo de execução dentro de um processo. As threads de um processo compartilham código, dados globais e arquivos abertos, mas cada uma tem seus próprios registradores, contador de programa e pilha (o TCB guarda esse contexto). O programa threads cria três threads que ficam ativas por alguns segundos.

Execute no terminal

sleep 1
./investigar.sh threads "$pid_threads"
wait "$pid_threads"
Referência para comparação · confira após prever
Todas as linhas mostram o mesmo PID; cada thread tem um TID (SPID) diferente.
&global é idêntico em todas; &local muda de uma thread para outra.
ps -T e /proc/PID/task listam 4 entradas: a main e as 3 threads criadas.

O contador que perde registros

Quatro threads somam 1 no mesmo contador, 20 000 vezes cada. Para a CPU, contador = contador + 1 são três passos: LER, PROCESSAR, ESCREVER (t07). Se o escalonador trocar de thread entre eles, uma atualização pode apagar outra. O programa tem três modos de proteção.

Execute no terminal
./contador sem
./contador ingenuo
./contador mutex
Referência para comparação · confira após prever
sem     : contador bem abaixo de 80000; perdidos > 0
ingenuo : ainda abaixo de 80000, embora exista uma "trava"
mutex   : contador=80000 e perdidos=0 em todas as rodadas
Os números exatos dependem da máquina e da carga do servidor.

A trava ingênua usa uma variável ocupado: espera ela valer 0 e então a marca com 1. Leia o trecho INGENUO em contador.c e localize a janela entre o teste e a marcação.

Cinco threads disputam três vagas. O semáforo começa com S = 3: wait(S) ocupa uma vaga ou bloqueia; signal(S) libera uma vaga e acorda quem espera (t08).

Referência para comparação · confira após prever
Três threads entram logo; duas chegam e ficam esperando (dentro=3).
Quando as primeiras saem, as que esperavam entram.
Maximo de threads dentro ao mesmo tempo: 3 (limite 3)
