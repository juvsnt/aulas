Atividade 1 · até 30 min · Medição real

A página só chega quando é usada

Objetivo: ver que o Linux só coloca uma parte do programa na memória RAM quando o programa a usa.

Conceitos: página (page) — pedaço de tamanho fixo da memória do programa · quadro (frame) — espaço do mesmo tamanho na RAM · falta de página (page fault) — aviso de que a página ainda não está na RAM · paginação sob demanda (demand paging). Slides t03 e t05.

O que fazer

  1. Veja o tamanho da página, em bytes:
    Cole no terminal
    getconf PAGESIZE
  2. O programa vai reservar 32 MiB, usar a metade (16 MiB) e depois usar tudo. Antes de rodar, responda a previsão.
  3. Abra o item abaixo, copie e cole no terminal para criar o programa:
    Criar demanda.c
    Cole no terminal para criar demanda.c
    cat > demanda.c <<'FIM'
/* demanda.c - paginacao sob demanda (Atividade 1).
 * Reserva 32 MiB e mostra, em cada etapa, quanta RAM o processo usa
 * e quantas faltas de pagina novas aconteceram. */
#define _DEFAULT_SOURCE
#include <stdio.h>
#include <string.h>
#include <sys/mman.h>
#include <sys/resource.h>
#include <unistd.h>

#define TAMANHO (32L * 1024 * 1024)   /* 32 MiB */

static long faltas_antes = 0;

/* RAM usada pelo processo (VmRSS em /proc/self/status), em KiB */
static long ram_kib(void) {
    char linha[256];
    long kib = 0;
    FILE *f = fopen("/proc/self/status", "r");
    if (f == NULL) return 0;
    while (fgets(linha, sizeof linha, f) != NULL)
        if (strncmp(linha, "VmRSS:", 6) == 0) sscanf(linha + 6, "%ld", &kib);
    fclose(f);
    return kib;
}

/* Mostra a RAM usada e as faltas de pagina desde a etapa anterior */
static void mostra(const char *etapa) {
    struct rusage uso;
    getrusage(RUSAGE_SELF, &uso);
    long faltas = uso.ru_minflt;     /* faltas resolvidas sem ler o disco */
    printf("%-18s | RAM usada: %5.1f MiB | faltas novas: %ld\n",
           etapa, (double)ram_kib() / 1024.0, faltas - faltas_antes);
    faltas_antes = faltas;
}

/* Escreve 1 byte em cada pagina, do inicio ate o byte 'fim' */
static void usa(char *mem, long fim, long pagina) {
    for (long i = 0; i < fim; i += pagina)
        mem[i] = 1;
}

int main(void) {
    long pagina = sysconf(_SC_PAGESIZE);
    printf("Pagina: %ld bytes. 32 MiB = %ld paginas.\n\n", pagina, TAMANHO / pagina);
    mostra("inicio");

    char *mem = mmap(NULL, TAMANHO, PROT_READ | PROT_WRITE,
                     MAP_PRIVATE | MAP_ANONYMOUS, -1, 0);     /* reserva */
    if (mem == MAP_FAILED) { perror("mmap"); return 1; }
    madvise(mem, TAMANHO, MADV_NOHUGEPAGE);   /* usar paginas de tamanho normal */
    mostra("reservou 32 MiB");

    usa(mem, TAMANHO / 2, pagina);
    mostra("usou a metade");
    usa(mem, TAMANHO, pagina);
    mostra("usou tudo");
    usa(mem, TAMANHO, pagina);
    mostra("usou tudo de novo");

    munmap(mem, TAMANHO);
    return 0;
}
FIM
  4. Compile e rode:
    Cole no terminal
    gcc -std=c11 -Wall -Wextra -O0 demanda.c -o demanda
./demanda

Observe: reservar quase não muda a RAM usada; cada página usada pela primeira vez gera uma falta.

Atividade 2 · até 30 min · Medição real

Cada processo no seu espaço

Objetivo: ver que cada processo tem seus próprios endereços e que o sistema bloqueia acessos proibidos.

Conceitos: endereço lógico (logical address) — o que o programa enxerga · endereço físico (physical address) — o lugar real na RAM · MMU (memory management unit) — peça do processador que traduz um no outro · proteção de memória. Slides t01, t02 e t04.

O que fazer

  1. Crie os dois programas:
    Criar isolado.c
    Cole no terminal para criar isolado.c
    cat > isolado.c <<'FIM'
/* isolado.c - cada processo tem o seu espaco de enderecamento (Atividade 2).
 * Pai e filho mostram o endereco e o valor da mesma variavel x. */
#define _POSIX_C_SOURCE 200809L
#include <stdio.h>
#include <sys/wait.h>
#include <unistd.h>

int x = 10;                       /* variavel global */

int main(void) {
    pid_t pid = fork();           /* cria uma copia deste processo */
    if (pid < 0) { perror("fork"); return 1; }
    if (pid == 0) {               /* filho */
        x = 99;                   /* muda x somente no filho */
        printf("filho: endereco de x = %p | x = %d\n", (void *)&x, x);
        return 0;
    }
    wait(NULL);                   /* pai espera o filho terminar */
    printf("pai:   endereco de x = %p | x = %d\n", (void *)&x, x);
    return 0;
}
FIM
    Criar so_leitura.c
    Cole no terminal para criar so_leitura.c
    cat > so_leitura.c <<'FIM'
/* so_leitura.c - protecao de memoria (Atividade 2).
 * Uma pagina vira "somente leitura": ler funciona, escrever e bloqueado. */
#define _DEFAULT_SOURCE
#include <stdio.h>
#include <sys/mman.h>
#include <unistd.h>

int main(void) {
    size_t pagina = (size_t)sysconf(_SC_PAGESIZE);
    char *p = mmap(NULL, pagina, PROT_READ | PROT_WRITE,
                   MAP_PRIVATE | MAP_ANONYMOUS, -1, 0);    /* uma pagina */
    if (p == MAP_FAILED) { perror("mmap"); return 1; }

    p[0] = 1;                          /* escrever ainda e permitido */
    mprotect(p, pagina, PROT_READ);    /* agora: somente leitura */

    printf("leitura ok: %d\n", p[0]);
    printf("tentando escrever...\n");
    fflush(stdout);                    /* mostra o texto antes de cair */
    p[0] = 2;                          /* proibido: a MMU avisa o SO */
    printf("escrita ok (nao deveria aparecer)\n");
    return 0;
}
FIM

Atividade 3 · até 30 min · Simulação

A memória acabou: quem sai?

Objetivo: comparar duas regras para escolher qual página sai da RAM quando não há quadro livre.

Conceitos: substituição de páginas (page replacement) · FIFO (first in, first out) — sai a página que entrou primeiro · LRU (least recently used) — sai a página usada há mais tempo. Slides t05 e t06.

Aqui o programa não mexe na memória real: ele simula as regras com uma lista de páginas.

O que fazer

  1. Faça à mão o FIFO com 3 quadros para a sequência de páginas 1 2 1 3 4 1 2 5 1 2. Para cada acesso, escreva F (falta) ou A (acerto) e, quando houver, a página que saiu.
  2. Crie o simulador:
    Criar substituicao.c
    Cole no terminal para criar substituicao.c
    cat > substituicao.c <<'FIM'
/* substituicao.c - SIMULACAO de substituicao de paginas (Atividade 3).
 * Uso: ./substituicao fifo|lru QUADROS PAGINA PAGINA ...
 * Exemplo: ./substituicao fifo 3 1 2 1 3 4 1 2 5 1 2 */
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

#define MAX_QUADROS 8
#define VAZIO (-1)

int main(int argc, char *argv[]) {
    if (argc < 4) {
        fprintf(stderr, "Uso: %s fifo|lru QUADROS PAGINA PAGINA ...\n", argv[0]);
        return 1;
    }
    int lru = strcmp(argv[1], "lru") == 0;
    if (!lru && strcmp(argv[1], "fifo") != 0) {
        fprintf(stderr, "Algoritmo deve ser fifo ou lru.\n");
        return 1;
    }
    int n = atoi(argv[2]);
    if (n < 1 || n > MAX_QUADROS) {
        fprintf(stderr, "Use de 1 a %d quadros.\n", MAX_QUADROS);
        return 1;
    }

    int quadro[MAX_QUADROS];   /* pagina guardada em cada quadro */
    int uso[MAX_QUADROS];      /* momento do ultimo uso (para o LRU) */
    for (int q = 0; q < n; q++) { quadro[q] = VAZIO; uso[q] = 0; }
    int mais_antigo = 0;       /* FIFO: quadro que recebeu pagina primeiro */
    int faltas = 0, tempo = 0;

    printf("%s com %d quadros\n\nacesso | quadros | resultado\n", lru ? "LRU" : "FIFO", n);
    for (int i = 3; i < argc; i++) {
        int pagina = atoi(argv[i]);
        tempo++;
        int achou = VAZIO;
        for (int q = 0; q < n; q++)
            if (quadro[q] == pagina) achou = q;

        int saiu = VAZIO;
        if (achou != VAZIO) {
            uso[achou] = tempo;                         /* acerto */
        } else {
            faltas++;                                   /* falta de pagina */
            int vitima = VAZIO;
            for (int q = 0; q < n && vitima == VAZIO; q++)
                if (quadro[q] == VAZIO) vitima = q;     /* ainda ha quadro livre */
            if (vitima == VAZIO) {                      /* memoria cheia */
                if (lru) {                              /* sai a usada ha mais tempo */
                    vitima = 0;
                    for (int q = 1; q < n; q++)
                        if (uso[q] < uso[vitima]) vitima = q;
                } else {                                /* sai a que chegou primeiro */
                    vitima = mais_antigo;
                    mais_antigo = (mais_antigo + 1) % n;
                }
                saiu = quadro[vitima];
            }
            quadro[vitima] = pagina;
            uso[vitima] = tempo;
        }

        printf("%6d | ", pagina);
        for (int q = 0; q < n; q++) {
            if (quadro[q] == VAZIO) printf(" -");
            else printf("%2d", quadro[q]);
        }
        if (achou != VAZIO) printf(" | acerto\n");
        else if (saiu == VAZIO) printf(" | falta\n");
        else printf(" | falta (saiu %d)\n", saiu);
    }
    printf("\nTotal: %d faltas em %d acessos\n", faltas, tempo);
    return 0;
}
FIM

Parte B · em casa · 50%

Problemas

Mostre as contas. Regras dos slides: página p = endereço ÷ tamanho (divisão inteira) e deslocamento d = resto; endereço físico = quadro × tamanho + d. Na segmentação, <s, d> é válido se d < limite; físico = base + d.

B1 · Base e limite

Processo A: base 3000, limite 1200. Processo B: base 9000, limite 500. Traduza ou indique erro: A 250 · A 1199 · B 480 · B 640.

B2 · Alocação contígua

Buracos livres, nesta ordem: 25 KB, 12 KB, 30 KB, 18 KB. a) Onde um pedido de 17 KB entra com first-fit, best-fit e worst-fit? Quanto sobra em cada caso? b) Uma partição fixa de 32 KB recebe um processo de 21 KB: qual tipo de fragmentação aparece e de quanto? c) Depois do best-fit do item a, chega um pedido de 35 KB. Há memória livre suficiente no total? Ele é atendido? Que fragmentação explica isso?

B3 · Segmentação

Segmento 0: base 2000, limite 500 · Segmento 1: base 5000, limite 300 · Segmento 2: base 800, limite 1000. Traduza ou indique trap: <0, 430> · <1, 350> · <2, 999>.

B4 · Paginação

Páginas de 2.048 bytes. Tabela: página 0 → quadro 6 (V) · página 1 → quadro 2 (V) · página 2 → inválida (I) · página 3 → quadro 9 (V). Para os endereços lógicos 2.500, 5.000 e 7.000, calcule p, d e o endereço físico, ou diga o que acontece.

B5 · TLB

A TLB (translation lookaside buffer) guarda 2 traduções e começa vazia; quando está cheia, sai a tradução usada há mais tempo. O processo acessa as páginas 3, 5, 3, 7, 5, 3, todas já na RAM. a) Marque hit ou miss em cada acesso. b) Quantas faltas de página aconteceram? Explique a diferença entre TLB miss e falta de página.

B6 · Tamanho da página

Um processo precisa de 20.000 bytes. Com páginas de 4 KiB (4.096 bytes) e de 8 KiB (8.192 bytes): quantas páginas ele ocupa e quantos bytes sobram sem uso (fragmentação interna)? Qual tamanho precisa de menos entradas na tabela de páginas?

B7 · Substituição

Com 3 quadros, inicialmente vazios, e a sequência 2 3 2 1 5 2 4 5 3 2 5 2, monte a tabela e conte as faltas para FIFO, OPT (ótimo), LRU e Clock (segunda chance, como no slide do t06). Qual teve menos faltas? Por que o OPT não é usado na prática?

B8 · Thrashing

Três processos têm conjuntos de trabalho (working set) de 40, 35 e 30 quadros, e a RAM tem 90 quadros livres. a) O que tende a acontecer? b) O que o SO deve fazer? c) Por que admitir mais processos quando a CPU parece ociosa piora a situação?
