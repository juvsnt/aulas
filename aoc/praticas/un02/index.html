02ISA, Assembly e CISC/RISC

Programe o alerta da estação

O sensor tem um ajuste didático de +2 °C. A função calibrar retorna 1 se a leitura corrigida for maior ou igual a 24, e 0 caso contrário. O total exibido continua sendo o total bruto. Preveja quantos alertas haverá para 12, 18, 24 e 30.

Cole o bloco inteiro. A primeira linha inicia a gravação; a linha final FIM, sozinha, encerra. O arquivo fica nesta pasta. O símbolo > no prompt durante a colagem significa que o shell está esperando o fim do bloco.

Criar estacao.c
cat > estacao.c <<'FIM'
#include <stdio.h>
int calibrar(int leitura) {
    int ajuste = 2;
    int corrigida = leitura + ajuste;
    if (corrigida >= 24) return 1;
    return 0;
}
int main(void) {
    int leituras[] = {12, 18, 24, 30};
    int total = 0, alertas = 0;
    for (int i = 0; i < 4; i++) {
        total += leituras[i];
        alertas += calibrar(leituras[i]);
    }
    printf("Total bruto=%d Alertas calibrados=%d\n", total, alertas);
    return 0;
}
FIM
Execute no terminal
gcc -std=c11 -Wall -Wextra -O0 -g estacao.c -o estacao
./estacao

gcc compila e liga; -std=c11 escolhe a linguagem; -Wall -Wextra habilitam avisos; -O0 desativa a maior parte das otimizações; -g guarda informações de depuração; -o dá nome ao executável. ./ executa o programa da pasta atual. Compilação bem-sucedida pode não imprimir nada.

Saída esperada · dados fixos
Total bruto=84 Alertas calibrados=2
03ISA, Assembly e CISC/RISC

Peça a tradução legível

O servidor documentado é x86-64. Confirme com uname -m. Os comandos de sintaxe Intel desta etapa se destinam a esse alvo; se aparecer outra arquitetura, peça ao professor a adaptação.

Execute no terminal
uname -m
gcc -O0 -S -masm=intel estacao.c -o estacao.s
sed -n '/^calibrar:/,/\.size[[:space:]]*calibrar/p' estacao.s

-S para antes da montagem e gera Assembly; -masm=intel escolhe a notação destino, origem. O filtro sed mostra só a função calibrar. Procure uma movimentação do ajuste 2, uma soma e uma comparação seguida de desvio.

Padrões possíveis, não transcrição garantida
mov ... , 2
...
add eax, edx
...
cmp ... , 23
jle ...

mov copia; add soma; cmp atualiza indicadores de comparação; jle desvia se menor ou igual, em uma comparação com sinal. O compilador pode testar “menor ou igual a 23” para implementar o caminho contrário de “maior ou igual a 24”. eax e edx são registradores; colchetes como [rbp-4] indicam um endereço de memória. Não são valores medidos de RAM física.

04ISA, Assembly e CISC/RISC

Encontre os bytes que a CPU executa

Execute no terminal
objdump -d -M intel --disassemble=calibrar estacao

objdump desmonta o executável; -d decodifica instruções; -M intel mantém a mesma sintaxe; --disassemble=calibrar limita a função. As colunas mostram endereço, bytes e Assembly.

Exemplo de trechos · endereços, registradores e bytes podem mudar
...: 01 d0       add eax,edx
...: 83 7d fc 17 cmp DWORD PTR [rbp-0x4],0x17

O hexadecimal 0x17 representa 23. Conte os bytes de duas instruções: x86-64 usa instruções de comprimentos variáveis. Isso não informa quantos ciclos elas levam. O arquivo .s é texto para humanos e para o montador; a CPU executa as instruções codificadas no executável.

05ISA, Assembly e CISC/RISC

Compare escolhas, não slogans

Para a operação de calibração, uma ISA de estilo load/store pode precisar explicitar carga, soma e armazenamento. O exemplo abaixo é pseudocódigo didático, não um programa MIPS ou RISC-V pronto para executar.

Modelo de estilo load/store · não execute no shell
LOAD R1, [leitura]
ADD  R1, R1, 2
STORE [corrigida], R1

Compare com referências à memória e registradores encontradas no x86. Não há compilador cruzado ou emulador confirmado no LIAC, então não vamos fingir uma medição ARM/RISC-V. Número de instruções, tamanho do código e tempo de execução são métricas diferentes. RISC não significa “sempre um ciclo” nem “sempre mais rápido”.

06ISA, Assembly e CISC/RISC

Teste uma mudança controlada

Desafio: o ajuste passa a +6. Faça a previsão antes de criar a variante. O original será preservado.

Execute no terminal
sed 's/ajuste = 2/ajuste = 6/' estacao.c > desafio.c
gcc -O0 desafio.c -o desafio
./desafio

sed substitui o texto indicado; > grava a variante em outro arquivo. Com ajuste +6, três leituras corrigidas atingem o limiar.

Saída esperada · dados fixos
Total bruto=84 Alertas calibrados=3
