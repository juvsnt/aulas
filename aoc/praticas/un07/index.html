02Paralelismo e arquiteturas não convencionais

Conte recursos, reconheça a quota

Execute no terminal
LC_ALL=C lscpu | head -n 18
python3 -c "import os; print('CPUs na afinidade:', len(os.sched_getaffinity(0)))"

O primeiro comando descreve o processador; o segundo informa em quais CPUs o processo pode ser escalonado. Essa afinidade não equivale à quota de tempo de CPU. A documentação do LIAC estabelece limite de uma CPU por conta: dois processos podem compartilhar essa quota, mesmo que o Linux mostre oito processadores lógicos.

Não há necessidade de uma GPU para o exercício. Esta prática não verifica disponibilidade de GPU, não usa CUDA e não conecta máquinas pela rede.
03Paralelismo e arquiteturas não convencionais

Separe o lote em duas partes

A estação terá dois trabalhadores locais: um soma 12 e 18, o outro soma 24 e 30. Cada um repete a soma 10 mil vezes para formar uma tarefa pequena e finita. Antes de executar, preveja as duas somas parciais e o total acumulado.

Cole o bloco inteiro. A primeira linha inicia a gravação; a linha final FIM, sozinha, encerra. O arquivo fica nesta pasta. O símbolo > no prompt durante a colagem significa que o shell está esperando o fim do bloco.

Criar paralelo.py
cat > paralelo.py <<'FIM'
import subprocess
import sys
from time import perf_counter

def trabalho(valores):
    total = 0
    for _ in range(10000):
        for valor in valores: total += valor
    return total

if __name__ == '__main__':
    if len(sys.argv) > 1:
        print(trabalho([int(v) for v in sys.argv[1:]]))
    else:
        inicio = perf_counter()
        serial = trabalho([12, 18, 24, 30])
        ts = perf_counter() - inicio
        inicio = perf_counter()
        # Dois filhos locais, sem rede; cada um calcula uma soma parcial.
        with subprocess.Popen([sys.executable, __file__, '12', '18'],
                              stdout=subprocess.PIPE, text=True) as p1:
            with subprocess.Popen([sys.executable, __file__, '24', '30'],
                                  stdout=subprocess.PIPE, text=True) as p2:
                a = p1.communicate(timeout=10)[0]
                b = p2.communicate(timeout=10)[0]
                if p1.returncode or p2.returncode:
                    raise SystemExit('Falha nos filhos; avise o professor.')
        paralelo = int(a) + int(b)
        tp = perf_counter() - inicio
        print(f'Serial={serial} Dividido={paralelo} Iguais={serial==paralelo}')
        print(f't_serial={ts:.6f}s t_dividido={tp:.6f}s')
        print(f'Speedup observado={ts/tp:.3f}')
        print('Amdahl p=0.5, N=2:', 1 / (0.5 + 0.5/2))
FIM

trabalho calcula uma soma local. subprocess.Popen inicia um novo interpretador; stdout=PIPE captura sua saída; communicate aguarda e recolhe o resultado. with fecha os recursos e espera os filhos. if __name__ == "__main__" delimita a entrada do script. Os argumentos distinguem a função de trabalhador da função de coordenador.

Execute e verifique antes de cronometrar

Execute no terminal
python3 paralelo.py
Resultados fixos e campos de tempo variáveis
Serial=840000 Dividido=840000 Iguais=True
t_serial=...s t_dividido=...s
Speedup observado=...
Amdahl p=0.5, N=2: 1.3333333333333333

O coordenador faz a redução: soma as duas parciais. 840000 é o total bruto 84 repetido 10 mil vezes, não uma nova temperatura. O caso dividido inclui criar os processos e coletar resultados; o serial não tem esse custo. Dois filhos existentes não provam execução simultânea em dois núcleos.

No servidor compartilhado, valores de tempo variam. Para esta tarefa curta, a versão dividida provavelmente será mais lenta, mas isso não é obrigatório. Se um filho for impedido pela política da conta, registre a restrição e faça a redução no papel; não altere os limites.

Saída esperada · dados fixos

Na organização, o coordenador recebe resultados de programas independentes: podemos relacioná-la a múltiplos fluxos de instruções e dados (MIMD), sem concluir que houve paralelismo físico. Aplicar a mesma adição simultaneamente a vários elementos em uma instrução vetorial seria SIMD. Uma lista em Python, por si só, não demonstra SIMD de hardware.

06Paralelismo e arquiteturas não convencionais

Calcule o limite e feche o projeto

Com fração paralelizável p e N processadores, Amdahl idealiza a aceleração como 1 / ((1-p) + p/N). Para p=0,5, dois processadores dão 1,33; mesmo com infinitos, o teto é 2. Comunicação, criação de processos e quotas podem reduzir o ganho observado.

Para o projeto da estação, uma GPU ou acelerador poderia ser útil para muitos sensores ou imagens, mas o custo de transferência e o volume precisam justificar a escolha. Arquiteturas heterogêneas combinam unidades especializadas; computação neuromórfica, processamento próximo à memória e computação quântica não são recursos testados por este exercício.

Execute no terminal
python3 -c "p=0.8; n=4; print(1 / ((1-p) + p/n))"
Saída esperada · dados fixos
2.5

Conclua a história: bits representam leituras; o compilador gera instruções; a CPU move e calcula; a hierarquia traz dados; E/S recebe e publica; pipeline sobrepõe estágios; processos dividem trabalho. Nenhuma dessas escolhas melhora o sistema isoladamente em todas as situações.
