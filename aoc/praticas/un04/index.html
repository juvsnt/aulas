02Hierarquia, cache e localidade

Reconheça os níveis da máquina real

Execute no terminal
getconf LEVEL1_DCACHE_SIZE
getconf LEVEL2_CACHE_SIZE
getconf LEVEL3_CACHE_SIZE
head -n 3 /proc/meminfo

getconf consulta capacidades de cache em bytes quando o ambiente as informa. /proc/meminfo apresenta informações de memória do sistema. MemTotal é a RAM visível ao Linux; não é a memória liberada para sua conta. Zero ou uma variável não reconhecida significa que essa consulta não forneceu a informação; registre “não informado”.

Exemplo de tamanhos compatíveis com o hardware documentado · confirme os valores reais
32768
262144
8388608
MemTotal: ... kB
Essas consultas descrevem capacidades. Não medem hits, misses ou latências. A memória virtual é uma abstração de endereçamento, não um sinônimo de swap; nem toda falta de página precisa ler o disco.
03Hierarquia, cache e localidade

Construa uma cache que cabe no papel

A estação agora organiza oito posições: dois lotes de quatro leituras. Vamos estudar os endereços dos elementos, não seus valores. A cache começa vazia, tem duas linhas e cada bloco contém dois elementos. Mapeamento: bloco = endereço // 2; linha = bloco % 2.

Cole o bloco inteiro. A primeira linha inicia a gravação; a linha final FIM, sozinha, encerra. O arquivo fica nesta pasta. O símbolo > no prompt durante a colagem significa que o shell está esperando o fim do bloco.

Criar cache.py
cat > cache.py <<'FIM'
import sys
# Cache didatica: mapeamento direto, 2 linhas, 2 elementos por bloco.
modo = sys.argv[1] if len(sys.argv) > 1 else 'sequencial'
ordens = {'sequencial': [0, 1, 2, 3, 4, 5, 6, 7],
          'saltos': [0, 4, 1, 5, 2, 6, 3, 7],
          'reuso': [0, 1, 0, 1, 0, 1, 0, 1]}
if modo not in ordens:
    raise SystemExit('Use: sequencial, saltos ou reuso')
cache = [None, None]
hits = 0
for endereco in ordens[modo]:
    bloco = endereco // 2
    linha = bloco % 2
    hit = cache[linha] == bloco
    hits += int(hit)
    cache[linha] = bloco
    print(f'end={endereco} bloco={bloco} linha={linha} '
          f'{"HIT" if hit else "MISS"}')
print(f'hits={hits} misses={8-hits} taxa={hits/8:.1%}')
FIM

// é divisão inteira; % é resto. Cada linha guarda o identificador do bloco residente. Se o bloco já está nessa linha, é HIT; caso contrário, é MISS e substituímos seu conteúdo. O modelo não representa os tamanhos reais do i7 e reinicia a cache a cada execução.

04Hierarquia, cache e localidade

Teste a ordem sequencial

Preveja: depois de buscar o endereço 0, o endereço 1 exigirá outro bloco?

Execute no terminal
python3 cache.py sequencial
Saída esperada · dados fixos
end=0 bloco=0 linha=0 MISS
end=1 bloco=0 linha=0 HIT
...
hits=4 misses=4 taxa=50.0%

O bloco traz o vizinho junto. Percorrer posições contíguas explora localidade espacial. Não é necessário que os números armazenados sejam parecidos: importa a proximidade dos endereços.

05Hierarquia, cache e localidade

Mude a ordem, mantenha os endereços

Execute no terminal
python3 cache.py saltos
python3 cache.py reuso
Resumos esperados · cada execução inicia com cache vazia
saltos: hits=0 misses=8 taxa=0.0%
reuso: hits=7 misses=1 taxa=87.5%

A ordem saltos é 0,4,1,5,2,6,3,7. Ela visita as mesmas oito posições do sequencial, mas provoca conflitos. Reuso alterna 0 e 1: volta ao mesmo bloco e explora localidade temporal. reuso não executa a mesma tarefa dos outros dois, portanto não serve para compará-los como algoritmos equivalentes.

06Hierarquia, cache e localidade

Escolha uma organização para os lotes

Desafio: a estação pode manter as leituras de cada lote juntas ou intercalar posições distantes. Recomende uma ordem para reduzir misses neste modelo e justifique com os números. Não extrapole as porcentagens para o cache real.

Um benchmark real de matrizes exigiria controlar tamanho, otimização, repetições e interferência da turma. O tempo de um comando no servidor compartilhado não identifica sozinho um cache miss.

O que descobrimos: o custo depende do caminho dos dados, não apenas da velocidade da ULA. Na próxima unidade, vamos trazer o lote do arquivo para o programa e produzir um relatório.
