Vidas, inventário e o estouro de bits

Investigue como o computador armazena a vida do herói em 1 byte, compreenda o clássico bug de overflow ao ultrapassar o limite e compacte poderes em bits.

Duração: 60 min Bits, bytes, bases numéricas e máscaras lógicas

Prof. Me. Juvenal Silva Neto · Ciência da Computação

Respostas salvas automaticamente neste navegador.

O cenário do jogo

O console de 8 bits e a memória do herói

No desenvolvimento do nosso jogo 2D, a memória RAM do console guarda o estado do personagem. Em sistemas com restrição de memória, cada byte conta! Em vez de usar variáveis grandes, a vida do herói é armazenada em apenas 1 byte sem sinal (com valores possíveis de 0 a 255), e os itens que ele carrega (espada, escudo, chave) são representados por bits individuais de status.

03 Representação em código

Crie e execute o programa do herói

Cole o bloco completo para criar o arquivo personagem.c e execute:

Criar personagem.c
cat > personagem.c <<'FIM'
#include <stdio.h>

int main(void) {
    // 1. Representacao da vida do personagem em 1 byte (0 a 255)
    unsigned char vida = 250;
    unsigned char pocao_cura = 10;
    
    // Demonstrando o estouro (overflow/wrap-around) tipico de jogos antigos:
    unsigned char vida_apos_cura = vida + pocao_cura;

    printf("=== STATUS DO PERSONAGEM (8 BITS) ===\n");
    printf("Vida inicial: %u\n", vida);
    printf("Tomou pocao de cura de +%u vidas...\n", pocao_cura);
    printf("Vida resultante com overflow de 8 bits: %u (o valor estourou!)\n\n", vida_apos_cura);

    // 2. Inventario e flags de status compactadas em bits:
    // Bit 0 (1): Vivo
    // Bit 1 (2): Espada equipada
    // Bit 2 (4): Escudo equipado
    // Bit 3 (8): Chave do castelo
    unsigned char status = 1 | 2 | 8; // Heroi vivo, com espada e chave (total = 11)

    printf("=== FLAGS DE INVENTARIO EM BITS ===\n");
    printf("Valor da variavel status: decimal=%u | hexadecimal=0x%02X\n", status, status);
    printf("Bit 0 - Heroi vivo?         %s\n", (status & 1) ? "SIM" : "NAO");
    printf("Bit 1 - Possui espada?      %s\n", (status & 2) ? "SIM" : "NAO");
    printf("Bit 2 - Possui escudo?      %s\n", (status & 4) ? "SIM" : "NAO");
    printf("Bit 3 - Tem chave da porta? %s\n", (status & 8) ? "SIM" : "NAO");

    return 0;
}
FIM
gcc -std=c11 -Wall -Wextra -O0 personagem.c -o personagem
./personagem

04 Interpretação

Por que a vida virou 4? O mistério do overflow

Em 1 byte (8 bits), o maior valor positivo sem sinal é 255 ($11111111_2$).

Quando somamos $250 + 10 = 260$, esse número precisaria de 9 bits ($100000100_2$). Como o registrador de 8 bits só consegue guardar os últimos 8 bits, o 9º bit (mais à esquerda) é descartado. Sobram apenas os bits $00000100_2$, que em decimal vale exatamente 4!

05 Desafio prático

Equipando o escudo do herói

No programa original, o herói não possuía o escudo (o Bit 2 de valor 4 estava desligado). Altere a linha do status no código para incluir o escudo (adicione | 4), recompile e execute:

Execute no terminal
sed -i 's/1 | 2 | 8/1 | 2 | 4 | 8/' personagem.c
gcc -std=c11 -Wall -Wextra -O0 personagem.c -o personagem
./personagem
Saída esperada no desafio

Bit 1 - Possui espada?      SIM
Bit 2 - Possui escudo?      SIM
Bit 3 - Tem chave da porta? SIM
