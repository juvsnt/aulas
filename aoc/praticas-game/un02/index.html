A caminhada do herói em instruções da ISA

Descubra como um simples comando de andar e uma colisão com a parede em C são traduzidos pelo compilador em instruções reais de máquina x86-64.

Duração: 60 min C11, Assembly x86-64 e desmontagem com objdump

Prof. Me. Juvenal Silva Neto · Ciência da Computação

Respostas salvas automaticamente neste navegador.

O cenário do jogo

Do código em C até os circuitos do processador

Quando o jogador aperta a tecla para a direita no controle, o motor do jogo executa uma função para atualizar a coordenada $X$ do herói: soma a velocidade e verifica se ele colidiu com a borda da tela. O processador não entende C diretamente: ele executa uma sequência de códigos numéricos (bytes de máquina) que correspondem a instruções Assembly como mov (copiar), add (somar) e cmp (comparar).

02 Código em C

Crie e execute a movimentação

Crie o arquivo movimento.c com a função que calcula a nova posição e impede de passar da parede:

Criar movimento.c
cat > movimento.c <<'FIM'
#include <stdio.h>

// Funcao que atualiza a coordenada X do personagem e trata colisao com a borda
int mover(int pos_x, int velocidade, int limite_tela) {
    int novo_x = pos_x + velocidade;
    if (novo_x > limite_tela) {
        novo_x = limite_tela; // Nao deixa o heroi atravessar a parede
    }
    return novo_x;
}

int main(void) {
    int pos_x = 75;
    int velocidade = 10;
    int borda = 80;

    int final_x = mover(pos_x, velocidade, borda);

    printf("=== MOVIMENTACAO E COLISAO NA TELA ===\n");
    printf("Posicao inicial: %d | Velocidade: +%d | Limite da borda: %d\n",
           pos_x, velocidade, borda);
    printf("Posicao final:   %d (colidiu com o limite)\n", final_x);

    return 0;
}
FIM
gcc -std=c11 -Wall -Wextra -O0 -g movimento.c -o movimento
./movimento
Saída esperada
=== MOVIMENTACAO E COLISAO NA TELA ===
Posicao inicial: 75 | Velocidade: +10 | Limite da borda: 80
Posicao final:   80 (colidiu com o limite)
03 Desmontagem Assembly

Olhando por dentro da função no processador

Use o utilitário objdump para desmontar a função mover diretamente do arquivo executável compilado:

Execute no terminal
objdump -d -M intel --disassemble=mover movimento
Trecho típico retornado pelo objdump (x86-64 sintaxe Intel)
...
add    eax,edx
...
cmp    eax,edx
jle    ...
mov    eax,edx
...
04 Interpretação da ISA

Relacionando o C ao Assembly

Observe como cada construção da linguagem C mapeou para a CPU:

  • pos_x + velocidade gerou a instrução add (soma na ULA).
  • if (novo_x > limite_tela) gerou a instrução cmp (comparação) seguida de um desvio condicional (como jle = jump if less or equal).
05 Desafio prático

Aumentando a borda da fase

Altere a borda da tela de 80 para 100 pixels, recompile e verifique se o herói agora atinge a posição 85 sem colidir:

Execute no terminal
sed -i 's/int borda = 80;/int borda = 100;/' movimento.c
gcc -std=c11 -Wall -Wextra -O0 movimento.c -o movimento
./movimento
Saída esperada no desafio
=== MOVIMENTACAO E COLISAO NA TELA ===
Posicao inicial: 75 | Velocidade: +10 | Limite da borda: 100
Posicao final:   85 (colidiu com o limite)
