P05

P05 · Modelo de chegada e entrega causal em dois receptores

Todos receberam na mesma ordem?

Base conceitual: Material da unidade 5 (PDF, nova aba). Tempo de referência: 60–90 min, ajustável pelo professor.

X define calibração +2; Y avalia uma leitura 22 usando essa calibração; Z é um registro independente. Quem gerou Y já conhecia X: X → Y. Os receptores recebem R1: Y,X,Z e R2: Z,X,Y.

Programa C fornecido · abra, leia e copie

A infraestrutura está pronta. Antes de executar, localize as operações destacadas na explicação da prática. O bloco abaixo escreve o fonte e compila com C11, avisos e sem otimização.

Criar e compilar grupo.c
cat > grupo.c <<'FIM'
#include <stdio.h>
#include <string.h>

typedef struct { char nome; int depende; } Mensagem;
static const Mensagem mensagens[] = {{'X', -1}, {'Y', 0}, {'Z', -1}};
static void observar(int r, const int ordem[3], int causal, int perde) {
    int chegou[3] = {0}, entregue[3] = {0}, calibracao = 0;
    printf("Receptor R%d\n", r);
    for (int passo = 0; passo < 3; ++passo) {
        int m = ordem[passo];
        if (perde && m == 0) { puts("X ausente no roteiro de entregas"); continue; }
        chegou[m] = 1;
        printf("Chegou %c\n", mensagens[m].nome);
        int mudou;
        do {
            mudou = 0;
            for (int i = 0; i < 3; ++i) {
                int dep = mensagens[i].depende;
                if (!chegou[i] || entregue[i] || (causal && dep >= 0 && !entregue[dep])) continue;
                entregue[i] = 1; mudou = 1;
                if (i == 0) calibracao = 2;
                printf("Entrega %c", mensagens[i].nome);
                if (i == 1) printf(" leitura=22 correcao=%d alerta=%s", calibracao,
                                   22 + calibracao >= 24 ? "SIM" : "NAO");
                putchar('\n');
            }
        } while (mudou);
    }
    int pendentes = 0;
    for (int i = 0; i < 3; ++i) if (chegou[i] && !entregue[i]) ++pendentes;
    printf("Pendentes=%d\n", pendentes);
}
int main(int argc, char **argv) {
    int causal = argc > 1 && strcmp(argv[1], "causal") == 0;
    int perde = argc > 2 && strcmp(argv[2], "sem-x") == 0;
    if (argc > 3 || (argc > 1 && !causal && strcmp(argv[1], "chegada")) ||
        (argc > 2 && !perde)) {
        fputs("Uso: ./grupo [chegada|causal] [sem-x]\n", stderr); return 2;
    }
    const int r1[] = {1, 0, 2}, r2[] = {2, 0, 1};
    observar(1, r1, causal, perde); observar(2, r2, causal, perde);
    return 0;
}
FIM
gcc -std=c11 -O0 -Wall -Wextra -Wpedantic grupo.c -o grupo

Baixar fonte grupo.c para revisão ou preparação.

Execute no terminal
./grupo chegada
Referência para comparação · abra depois de prever
R1: Entrega Y leitura=22 correcao=0 alerta=NAO
R2: Entrega Y leitura=22 correcao=2 alerta=SIM
Pendentes=0 em ambos.

Interprete o programa e a saída

chegou e entregue são estados distintos. No modo causal, Y fica retida até que sua dependência X esteja entregue; o laço reexamina mensagens após cada avanço. Z não depende de X nem de Y. Entregar causalmente não exige uma ordem total entre eventos independentes. Os dois receptores representam um grupo selecionado, não todos os computadores de uma rede.

Mudança orientada

Mude apenas a política de chegada para causal. Depois mantenha a política causal e retire X do roteiro de chegada com sem-x. Preveja os alertas e a fila pendente.

Executar mudança orientada
./grupo causal
./grupo causal sem-x
Referência para comparação · abra depois de prever
Causal: ambos entregam Y com correcao=2 alerta=SIM.
R1 entrega X,Y,Z; R2 entrega Z,X,Y: ordens totais diferentes.
Causal sem-x: Pendentes=1 em cada receptor; Y não é entregue.
Limites da conclusão: O programa conhece uma dependência explícita e três mensagens; não implementa multicast de rede nem um algoritmo geral de relógios vetoriais. Ausência e reordenação são injetadas. Garantia de ordem e garantia de entrega são propriedades diferentes.
