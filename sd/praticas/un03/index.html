P03

P03 · Modelo determinístico de eventos e relógios

Qual evento pode ter causado outro?

Base conceitual: Material da unidade 3 (PDF, nova aba). Tempo de referência: 60–90 min, ajustável pelo professor.

O produtor A envia m para B; B responde r para A. Compare horários físicos fictícios e relógios de Lamport sem ajustar o relógio do servidor.

Programa C fornecido · abra, leia e copie

A infraestrutura está pronta. Antes de executar, localize as operações destacadas na explicação da prática. O bloco abaixo escreve o fonte e compila com C11, avisos e sem otimização.

Criar e compilar lamport.c
cat > lamport.c <<'FIM'
#include <errno.h>
#include <stdio.h>
#include <stdlib.h>

static int local(int *clock, const char *nome, int fisico) {
    ++*clock;
    printf("%s fisico=%d L=%d\n", nome, fisico, *clock);
    return *clock;
}
static void receber(int *clock, int mensagem, const char *nome, int fisico) {
    if (*clock < mensagem) *clock = mensagem;
    (void)local(clock, nome, fisico);
}
int main(int argc, char **argv) {
    int desvio = 20;
    if (argc > 2) return 2;
    if (argc == 2) {
        char *fim; errno = 0; long n = strtol(argv[1], &fim, 10);
        if (errno || !*argv[1] || *fim || n < -50 || n > 50) {
            fputs("Uso: ./lamport [desvio_B:-50..50]\n", stderr); return 2;
        }
        desvio = (int)n;
    }
    int a = 0, b = 0;
    (void)local(&a, "A1 local", 10);
    (void)local(&b, "B1 local", 10 + desvio);
    (void)local(&b, "B2 local", 11 + desvio);
    int mensagem = local(&a, "A2 envia m", 12);
    receber(&b, mensagem, "B3 recebe m", 13 + desvio);
    (void)local(&a, "A3 local", 14);
    mensagem = local(&b, "B4 envia r", 15 + desvio);
    receber(&a, mensagem, "A4 recebe r", 16);
    puts("A1 e B2 sao concorrentes: nao ha caminho de mensagens entre eles.");
    puts("Ordem L(A1)<L(B2) nao prova que A1 causou B2.");
    return 0;
}
FIM
gcc -std=c11 -O0 -Wall -Wextra -Wpedantic lamport.c -o lamport

Baixar fonte lamport.c para revisão ou preparação.

Execute no terminal
./lamport 20
Referência para comparação · abra depois de prever
A1 local fisico=10 L=1
B2 local fisico=31 L=2
A2 envia m fisico=12 L=2
B3 recebe m fisico=33 L=3
B4 envia r fisico=35 L=4
A4 recebe r fisico=16 L=5

Interprete o programa e a saída

local incrementa o contador antes de registrar. receber aplica max(relógio local, timestamp recebido) + 1. O parâmetro desloca apenas os horários físicos de B, não sua velocidade: representa desvio, não deriva. A ordem de impressão foi escolhida pelo roteiro; ela não estabelece por si só causalidade entre processos. Acontece-antes decorre da ordem local, envio/recebimento e transitividade. A1 e B2 não estão ligados por um caminho dirigido. Ordenar pares (L,id) resolve empates por convenção, sem demonstrar causa.

Mudança orientada

Altere apenas o desvio de B de +20 para -20. Antes de executar, indique quais colunas e relações devem permanecer iguais.

Executar mudança orientada
./lamport -20
Referência para comparação · abra depois de prever
B2 local fisico=-9 L=2
B3 recebe m fisico=-7 L=3
B4 envia r fisico=-5 L=4
A4 recebe r fisico=16 L=5
Limites da conclusão: Não há relógios remotos reais, espera, NTP ou medição de RTT. Lamport respeita acontece-antes, mas timestamps crescentes não bastam para detectar causalidade. Sincronização física exige hipóteses de erro e atraso; não é substituída pelo modelo.
